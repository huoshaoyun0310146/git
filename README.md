# git

Claude Desktop / Claude Code 云端环境的示例仓库。

## Awesome Claude Design

本仓库已安装 Awesome Claude Design 的设计规范资产：

- `DESIGN.md` — Claude (Anthropic) 风格设计系统，来源于 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 的 `design-md/claude/DESIGN.md`，MIT 许可。
- `awesome-claude-design/INSTALL.md` — 安装与配置清单、来源、本地完整集合路径、使用方法。

用法：在 Claude Code 中把 `DESIGN.md` 作为 UI 设计的 source of truth；或在 Claude Design 里通过 *Create new design system → Add assets* 上传该文件，生成完整 Design System。

> 说明：本机 Claude Desktop 目前运行在第三方推理（3p）模式，该模式下 Claude Design / Artifacts 不可用，需切换为官方订阅账号登录后方可实际使用设计能力。本仓库中的资产安装与配置本身已完成。
